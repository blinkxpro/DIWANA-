Requirements:

1. Browser tab ka title Vercel ya kisi default naam ka nahi hona chahiye.
   Set:
   "DIWANA — Mumbai Travel Experience"

2. DIWANA ka custom favicon use karo.

4. Website ke UI mein kahin bhi:
   
   - Vercel
   - Vite
   - React default branding
   - starter/template text
     agar visible ho aur website ke liye unnecessary ho, identify karke remove karo.

6. SEO metadata bhi DIWANA ke according set karo:
   
   - title: "DIWANA — Mumbai Travel Experience"
   - description: "Experience Mumbai with DIWANA — a unique Indian bus travel experience."
   - theme-color website ke existing design ke according rakho.

7. Agar project Vite + React hai toh Vite ke required configuration ko break mat karo.

8. Changes complete karne ke baad project build karke verify karo:
   "npm run build"

9. Build error aaye toh khud fix karo.

10. Finally mujhe batao:

- Kaun-kaun si files change ki
- Favicon kis file se use ho raha hai
- Final page title kya hai
- Build successful hua ya nahi
